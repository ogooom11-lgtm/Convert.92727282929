## ب. حالات الحافة

| نوع الاختبار | الحالة | معيار النجاح | ☐ |
|---|---|---|---|
| اسم عربي + مسافات | «تقرير المشروع ٢٠٢٦.docx» | تحويل ناجح | ☐ |
| مسار طويل | مجلد متداخل عميق | تحويل ناجح | ☐ |
| ملف تالف | PDF/فيديو مقطوع | رسالة خطأ قابلة للفهم، التطبيق يبقى يعمل | ☐ |
| ملف كبير | فيديو ٥٠٠ م.ب+ | لا تجمّد للواجهة، الإلغاء يعمل | ☐ |
| ملف مقيّد | PDF بكلمة مرور | رسالة تطلب كلمة المرور (لا فشل صامت) | ☐ |
| إلغاء | ضغط «إلغاء الجارية» أثناء التنفيذ | العملية تُقتل، الحالة «أُلغي»، لا ملف نصف مكتمل | ☐ |
| عملية متكررة | نفس الملف مرتين | لا استبدال: «الاسم (1).ext» | ☐ |
| أداة ناقصة | حذف أداة من `tools` | التطبيق يفتح ويُخفي عملياتها فقط | ☐ |
| نافذة واحدة | تشغيل التطبيق مرتين | تفتح نافذة واحدة، والثانية تُظهر الأولى | ☐ |
| سحب وإفلات | سحب ملف من المستكشف | يُضاف فورًا | ☐ |
| نوع مختلط | صورة + فيديو معًا | العمليات تُعرض لفئة الملف الأول، والبقية تُقبل للعمليات الجماعية فقط | ☐ |
| الاختصارات | Ctrl+O / Ctrl+1…4 | تعمل | ☐ |
| تبديل الثيم | نظام ← داكن ← فاتح | لا أخطاء، لون شريط العنوان يتغيّر | ☐ |

## ج. معايير القبول النهائية

- ☐ كل عملية من الثلاثين تعمل على ملف حقيقي، ومن داخل التطبيق.
- ☐ كل صيغة مذكورة تُفتح فعلًا كمدخل.
- ☐ لم يُرفع أي ملف إلى الإنترنت في أي مرحلة.
- ☐ لم يُفتح ترمينال مرة واحدة لتحويل ملف (كل شيء بالسحب والإفلات).
- ☐ الفشل دائمًا يُفسَّر برسالة قابلة للفهم، والتطبيق لا يتوقف.
- ☐ حذف أي أداة من `tools` لا يعطّل التطبيق.
- ☐ أسبوع كامل من الاستخدام الفعلي بلا رجوع لأي موقع تحويل.
